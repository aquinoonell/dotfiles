# Mekanikos wallpapers (6K)

Full-resolution PNGs from [Mekanikos](https://mikkelmalmberg.com) live here. Theme `backgrounds/` folders symlink into this tree so macOS gets native 6016×3384 files.

These binaries are gitignored (~600MB). Populate from the zip:

```bash
~/dotfiles/bin/mekanikos-wallpapers "/path/to/Mekanikos Wallpapers 1.0.zip"
```

Default zip location tried: `~/Downloads/Mekanikos Wallpapers 1.0.zip`
