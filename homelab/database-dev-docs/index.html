Core Concepts

  • Buffer pool — database-managed page cache. Postgres: shared_buffers. LRU eviction.
  • WAL — write-ahead log. Changes logged before applied. Crash recovery via ARIES.
  • MVCC — multiple row versions. Readers don't block writers. Postgres uses MVCC.
  • 2PL — two-phase locking for serializability.
  • Volcano model — operators call next() for one row. Maps to Rust Iterator.
  • Vectorized execution — operators return batches (RecordBatch). DataFusion uses this.

Apache Arrow in Rust

Columnar in-memory format. DataFusion's data layer. Zero-copy sharing between processes/languages.

Key Types

TypePurpose
SchemaColumn names and types
FieldOne column: name, DataType, nullable
RecordBatchChunk of columnar data — unit of execution
ArrayRefArc<dyn Array> — type-erased column
Int32Array, StringArrayTyped column arrays

Creating a RecordBatch

use arrow::array::{Int32Array, StringArray, ArrayRef};
use arrow::record_batch::RecordBatch;
use arrow::datatypes::{DataType, Field, Schema};
use std::sync::Arc;

let schema = Arc::new(Schema::new(vec![
    Field::new("id", DataType::Int32, false),
    Field::new("name", DataType::Utf8, true),
]));

let batch = RecordBatch::try_new(schema, vec![
    Arc::new(Int32Array::from(vec![1, 2, 3])),
    Arc::new(StringArray::from(vec![Some("alice"), None, Some("bob")])),
])?;

Downcasting ArrayRef

// By index
let col = batch.column(0);
let ids = col.as_any().downcast_ref::<Int32Array>().unwrap();

// By name
let idx = batch.schema().index_of("fare_amount")?;
let col = batch.column(idx);

// Ergonomic: AsArray trait
match col.data_type() {
    DataType::Utf8 => { /* col.as_string() */ }
    DataType::Int64 => { /* col.as_primitive() */ }
    _ => {}
}

Null Handling

Arrow arrays iterate as Option<T>. Use .unwrap_or_default() for nulls, not .unwrap().

Version Rule

Import Arrow through DataFusion to avoid version mismatches:

// WRONG: use arrow::array::Int64Array;
// RIGHT:
use datafusion::arrow::array::Int64Array;

Parquet in Rust

Columnar on-disk format. Complementary to Arrow (disk vs memory).

Reading Parquet

use std::fs::File;
use parquet::arrow::arrow_reader::ParquetRecordBatchReaderBuilder;

let file = File::open("data.parquet")?;
let builder = ParquetRecordBatchReaderBuilder::try_new(file)?;

println!("Row groups: {}", builder.metadata().num_row_groups());
println!("Schema: {}", builder.schema());

let mut reader = builder.build()?;
while let Some(batch) = reader.next() {
    let batch = batch?;
    println!("{} rows, {} cols", batch.num_rows(), batch.num_columns());
}

Parquet Structure

UnitDescription
Row GroupHorizontal partition (~50K-1M rows)
Column ChunkAll values for one column in a row group
PageSmallest storage unit within a column chunk

Writing Parquet

use parquet::arrow::ArrowWriter;

let file = File::create("output.parquet")?;
let mut writer = ArrowWriter::try_new(file, batch.schema(), None)?;
writer.write(&batch)?;
writer.close()?;

DataFusion Query Engine

Architecture Pipeline

SQL string
  → sqlparser-rs (AST)
  → LogicalPlan (WHAT to compute)
  → LogicalOptimizer (predicate/projection pushdown)
  → PhysicalPlanner
  → ExecutionPlan tree (HOW to compute)
  → SendableRecordBatchStream (async batches)
  → Vec<RecordBatch>

Basic Usage

use datafusion::prelude::*;

#[tokio::main]
async fn main() -> datafusion::error::Result<()> {
    let ctx = SessionContext::new();
    ctx.register_parquet("taxi", "yellow_tripdata.parquet",
        ParquetReadOptions::default()).await?;

    let df = ctx.sql("
        SELECT passenger_count, AVG(tip_amount)
        FROM taxi GROUP BY passenger_count
    ").await?;

    df.explain(false, false)?.show().await?;  // see the plan
    df.show().await?;
    Ok(())
}

Rust Patterns for Databases

Buffer Pool with RwLock

use std::sync::{Arc, RwLock};
use std::collections::HashMap;

struct BufferPool {
    frames: Arc<RwLock<HashMap<PageId, Frame>>>,
}

impl BufferPool {
    fn fetch_page(&self, id: PageId) -> bool {
        self.frames.read().unwrap().contains_key(&id)
    }
    fn evict_page(&self, id: PageId) {
        self.frames.write().unwrap().remove(&id);
    }
}

WAL Log Sequence Number

use std::sync::atomic::{AtomicU64, Ordering};

fn allocate_lsn(counter: &AtomicU64) -> u64 {
    counter.fetch_add(1, Ordering::SeqCst)
}
