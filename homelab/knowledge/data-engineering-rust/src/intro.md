# Data Engineering in Rust

Learn columnar data processing with **Apache Arrow**, **Parquet**, and **DataFusion** — entirely from your homelab.

## Prerequisites

- Basic Rust (`cargo`, ownership, `Result`)
- Homelab access: `http://labs.lan` (this book) + `http://kiwix.lan` (Rust DevDocs ZIM)

## Lab environment

```bash
cd ~/dotfiles/homelab/knowledge/data-engineering-rust/labs/01-read-parquet
cargo run
```

Sample data lives in `labs/data/sample.parquet`.
